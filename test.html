Detailed Role Specifications

ROLE 1

Student Profile

STU-101 (Student 1)
What We CAN Do
  • Browse all campus facilities across engineering, multimedia, and hardware kits.
  • Filter catalog by asset category (Labs, Seminars, Hardware) and search by keyword or specs.
  • Apply GoF Decorator add-ons with dynamic price computation ($25 Extended Hours, $50 Priority Setup, $35 Technician, $20 Insurance).
  • Submit booking requests with purpose, duration, date, and timeslot.
  • View personal reservation history with live status badges (PENDING, APPROVED, REJECTED, CANCELLED).
  • Cancel personal pending or approved reservations before timeslot begins.
  • Generate and print official North South University Bursar Vouchers with verification watermark and QR code.
What We CANNOT Do (Security Traps)
  • Cannot access Admin Approvals Desk ERR_UNAUTHORIZED_ROLE
  • Cannot access Department Master Schedule tab
  • Cannot approve or reject reservations via proxy ERR_UNAUTHORIZED_ROLE
  • Cannot book offline facilities in maintenance ERR_FACILITY_OFFLINE
  • Cannot exceed fair-use quota of 3 concurrent active bookings ERR_QUOTA_EXCEEDED
  • Cannot double-book the same facility on the same day ERR_SAME_DAY_MONOPOLIZATION
  • Cannot access Audit Logs, JSON DB Engine, or Super Admin portals.
All Available Options & UI Controls
  • Category filter pills: All, Labs, Seminar Halls, Hardware Kits.
  • Real-time search bar with instant query matching.
  • Booking Modal options: Date picker, 2-hour timeslot selector, Purpose textarea.
  • Decorator checkboxes: 4 optional add-ons with dynamic live total updates.
  • Voucher Modal: Print to paper/PDF button, Dismiss modal.
ROLE 2

Faculty Profile

FAC-202 (Faculty 1)
What We CAN Do
  • All Student capabilities: Catalog browsing, multi-criteria filtering, search, decorator add-ons.
  • Inspect Department Master Schedule across all departmental assets and timeslots.
  • Submit reservations with verified Faculty Academic Priority credentials.
  • Benefit from Faculty Priority Queue Strategy: Preempts student bookings in approval queue.
  • View personal faculty course & makeup bookings in history.
  • Print official Bursar vouchers for course departmental billing.
What We CANNOT Do (Security Traps)
  • Cannot approve or reject requests for students or other faculty ERR_UNAUTHORIZED_ROLE
  • Cannot self-approve their own course bookings ERR_UNAUTHORIZED_ROLE
  • Cannot access Admin Approvals Desk
  • Cannot toggle facility maintenance availability ERR_UNAUTHORIZED
  • Cannot access Audit Logs or JSON Database Engine
  • Cannot access Super Admin console
All Available Options & UI Controls
  • Master Department Schedule view with asset grid and slot occupancy.
  • Faculty Priority Academic booking options.
  • Course & Makeup session reason tagging.
  • All standard catalog filters and decorator add-on checkboxes.
ROLE 3

Facility Admin (1-to-1 Jurisdiction)

ADM-303 (Admin 1 - LAB-101)
What We CAN Do
  • Access Approval Desk tab strictly filtered to assigned facility (1-to-1 Injective Jurisdiction).
  • Approve pending reservations for assigned facility with optional remarks.
  • Reject pending reservations for assigned facility with mandatory documentation.
  • Toggle operational status of assigned facility (Set Offline for Maintenance / Set Online).
  • Switch Queue Allocation Policy via segmented buttons (FCFS Standard vs Faculty Priority).
  • View Department Master Schedule and personal bookings.
What We CANNOT Do (Security Traps)
  • Cannot approve requests for other campus facilities ERR_UNAUTHORIZED_RESOURCE_SCOPE
  • Cannot approve their own personal reservations ERR_SELF_APPROVAL_PROHIBITED
  • Cannot access System Audit Logs SECURITY_VIOLATION
  • Cannot access JSON Database Engine SECURITY_VIOLATION
  • Cannot access Super Admin portal
  • Cannot register or delete campus facilities or user accounts
All Available Options & UI Controls
  • Queue Strategy Segmented Buttons: FCFS (Standard) or Faculty Priority.
  • Facility Action: Set Offline (Maintenance) / Set Online (Available).
  • Approval Desk actions: Approve (green button) and Reject (red button).
  • Decision Remarks input prompt for audit trail compliance.
ROLE 4

Super Admin (Root System Authority)

ADM-001 (Admin 1)
What We CAN Do
  • Access isolated #sadmin executive login portal.
  • Root uninhibited access across all 7 portals (Catalog, Schedule, My Bookings, Approvals, Audit, DB Engine, Super Admin).
  • 1-to-1 Injective Facility Jurisdiction Manager: Assign or revoke facility management rights to admins.
  • User Directory CRUD: Create, read, update, and delete institutional users across all roles.
  • Facility Inventory CRUD: Register new campus facilities, edit specs, decommission facilities.
  • Global Approval Override: Review and approve/reject bookings across ANY facility university-wide.
  • Inspect complete cryptographic Audit Log trail with SHA event verification hashes.
  • Inspect, test, and export raw relational JSON Database Engine tables.
What We CANNOT Do (Security Traps)
  • Cannot log in via standard public login modal (isolated strictly to /sadmin route).
  • Cannot assign 1 admin to multiple facilities ERR_ADMIN_ALREADY_ASSIGNED
  • Cannot assign multiple admins to the same facility ERR_RESOURCE_ALREADY_ASSIGNED
  • Cannot delete the root Super Administrator account ERR_PROTECTED_ENTITY
  • Cannot delete a user holding active/confirmed reservations ERR_USER_IN_USE
All Available Options & UI Controls
  • Jurisdiction Manager: Facility dropdown, Admin dropdown, Assign Exclusive Jurisdiction, Revoke Jurisdiction.
  • User CRUD Form: Name, Email, Password, Role selector, Department, NSU ID, Save/Cancel.
  • Facility CRUD Form: Asset Name, Type, Location, Capacity, Base Rate, Specs, Save/Decommission.
  • Audit Controls: Export JSON Audit Trail, Verify Cryptographic Hash.
  • Database Engine: Download Table JSON, View Table JSON, Import Table JSON.
